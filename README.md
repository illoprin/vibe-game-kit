# OGK Concrete Yard

Небольшая FPS-сцена на Rust + `wgpu`. По умолчанию загружается `assets/map1.map`: площадка 30×30 с бетонными барьерами, ящиками, платформами и ступенями. При запуске детальный карабин из `assets/carbine.json` отображается в руках персонажа; для него созданы отдельные текстуры `gunmetal.ppm` (оружейная сталь) и `walnut.ppm` (ореховое дерево).

## Запуск

```sh
cargo run --release
```

Можно передать путь к другой карте: `cargo run --release -- maps/another.ogkmap`.

## Управление

- Клик по окну — захват мыши; движение мышью — обзор.
- `W` / `A` / `S` / `D` — ускоряющееся движение.
- `Shift` — бег; при ходьбе и беге есть процедурная тряска камеры и покачивание карабина.
- `Space` — прыжок; столкновения с блоками обрабатываются через AABB.
- `Esc` — открыть/закрыть меню паузы; `Resume` возвращает в игру.
- Во вкладке `Graphics` меню паузы настраиваются разрешение shadow map, фильтр теней (PCF/VSM), SSAO, vignette и экспозиция ACES.
- Настройки хранятся в `settings.toml`: графика сохраняется при выходе из меню/смене вкладки, карта — при изменении поля в меню. Путь карты применяется при следующем запуске; аргумент командной строки имеет приоритет.

## Текстовый формат `.map`

Файл — UTF-8 текст, `#` начинает комментарий. Пути к текстурам и моделям задаются относительно файла карты.

```text
MAP 1
# пути задаются относительно папки с картой
material concrete concrete.ppm
material crate crate.ppm
material gunmetal gunmetal.ppm
material walnut walnut.ppm
floor 30 concrete
box -1.5 1.0 -4.5 6.0 2.0 0.55 concrete
model prop.obj 0 0 0 1 crate
viewmodel carbine.json gunmetal
# sun <направление-к-солнцу xyz> <линейный-rgb> <интенсивность>
sun 0.35 0.8 -0.4 1.0 0.93 0.78 2.4
# point <позиция xyz> <линейный-rgb> <интенсивность> <радиус>
point -4.0 4.5 2.0 1.0 0.72 0.42 18.0 11.0
point 4.5 3.8 -5.0 0.45 0.68 1.0 16.0 10.0
```

Директивы: `material <имя> <ppm>`, `floor <размер> <материал>`, `box <x> <y> <z> <ширина> <высота> <глубина> <материал>`, `model <файл.obj|файл.mjson> <x> <y> <z> <масштаб> <материал>`, `viewmodel <файл.obj|файл.mjson> <материал>`, `sun <dx> <dy> <dz> <r> <g> <b> <интенсивность>` и до двух директив `point <x> <y> <z> <r> <g> <b> <интенсивность> <радиус>`. Направление солнца задаётся от поверхности к источнику; цвет — в линейном RGB. Материал должен быть объявлен заранее.

## Рендеринг и эффекты

- Направленный солнечный свет использует shadow mapping с выбором 3×3 PCF или Variance Shadow Maps; разрешение 256, 512, 1024 или 2048 можно менять в меню паузы.
- Deferred pipeline записывает albedo, мировые нормали и глубину сцены в G-buffer, затем рассчитывает освещение в HDR-буфер `RGBA32Float`. Глубина viewmodel хранится отдельно, чтобы её overlay не затирал глубину мира.
- Два point light из карты освещают G-buffer. Normal-oriented hemisphere SSAO проходит отдельные raw и bilateral blur этапы; глубина viewmodel исключена из AO и фильтра, чтобы оружие не создавало чёрных ореолов. В Graphics можно выключить эффект и менять intensity (0–8) и радиус.
- Финальный проход применяет настраиваемые vignette и экспозицию ACES tone mapping.

## Модели и текстуры

- `.obj`: вершины `v`, UV `vt`, нормали `vn`, грани `f` (включая отрицательные индексы и полигоны; полигоны триангулируются). `mtl` не загружается — материал модели задаётся в карте.
- `.mjson` / Minecraft block-model JSON: `elements` с `from`/`to`, `faces` с `texture`, `textures` и повороты элементов по `axis`/`angle`. Текстура грани связывается с материалом карты по имени; для остального используется материал из директивы модели.
- Используется текстовый PPM (`P3`), изображения должны быть не больше 32×32. Отсутствующая или некорректная текстура процедурно создаётся и сохраняется по указанному пути; фильтрация nearest.

Код движка разнесён по небольшим модулям в `src/`: камера/физика, карта/модели, меши, GPU-ресурсы и рендерер.
